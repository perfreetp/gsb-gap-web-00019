# 中药材 GAP 培训考核一体化平台

面向中药材种植基地与饮片企业，把「谁培训过、谁考过了、哪块地归谁管」绑定管理的 Web 平台。
零外部运行时依赖：Node.js（内置 `node:sqlite`）+ 原生前端，数据落 SQLite 单文件。

## 快速开始

```bash
node server/seed.js     # 首次运行：初始化并写入演示数据
npm start               # 或 node server/index.js，默认 http://localhost:3000
```

浏览器打开 http://localhost:3000 ，演示账号（密码 = 账号 + `123`）：

## 功能总览

**人员台账（基地管理员）**
- 姓名、身份证（脱敏展示）、合作社、地块、长期/季节性用工、联系方式
- CSV 批量导入，按身份证号 / 姓名+手机号自动查重并合并；重复人员可人工合并，培训/成绩/证书自动归集
- 按工种（育苗、移栽、除草、施肥、采收、初加工、仓储）挂技能标签，工种对应必需培训科目

**培训（技术员排课，药农扫码）**
- 按农时排场次：时间、地点、地块、讲师、内容、应到工种、学时；自动生成应到名单
- 药农扫码报名、现场扫码签到；弱网先存浏览器本地队列，联网补传，`client_nonce` 幂等去重
- 技术员代签/补录并留痕；结训自动列出应到未到人员并推送提醒；讲师可被打分评价

**课程学习**
- GAP 规范、农药安全间隔期、禁用农药清单、采收加工标准等课件/短视频
- 逐人记录观看时长与章节完成度（观看满 90% 且章节全完成为学完），未学完不能报考对应科目

**考核**
- 按品种 / 章节 / 难度 / 题型抽题，同场自动生成 A、B 卷
- 设置开考时间、时长、及格线、补考次数；手机答题，断线续考，倒计时归零自动交卷
- 选择/判断自动判分，识图、简答推技术员评阅，第二人评阅自动双评取平均
- 支持纸质卷成绩回录；药农可在线申诉，技术员复核留痕、必要时调整分数

**合格证与复训**
- 合格即生成电子培训合格证（编号、科目、成绩、发证/有效期）
- 农药安全类科目设有效期（24/12 个月），到期前 30 天自动扫描推送复训提醒

**采收持证校验**
- 采收登记选择地块与作业人员，系统校验采收工种必需科目是否持有效证书
- 未持证红色警示且必须逐人填写原因，自动推送补训提醒；记录随批次永久留痕
- 一键导出 CSV 留痕单供下游客户/检查方调阅

**统计与权限**
- 按地块、合作社、科目维度的合格率；缺训缺证名单；药农年度学时（线下+线上）；讲师授课评分
- 企业质控看全量，基地管理员/技术员只看本基地，药农只看本人
- 审计日志记录登录、成绩修改、签到补录、证书签发、采收登记等所有关键操作

## 目录结构

```
server/
  index.js        HTTP 服务、路由、鉴权、静态文件
  db.js           SQLite 建表（26 张表）
  util.js         密码哈希、令牌、审计、通知、证书编号/有效期
  exam-core.js    抽题组卷 A/B 卷、自动判分、双评、断线续考、超时交卷、发证
  seed.js         演示数据
  api/            auth/org/workers/training/courses/exam/harvest/stats
public/           原生 HTML/CSS/JS 单页应用（core.js + pages/*）
data/gap.db       SQLite 数据文件（运行后生成）
```

## 关键业务规则（后端实现位置）

- 判分规则 / 及格线 / 补考配额：`server/exam-core.js`
- 签到与答题幂等去重：`attendance.client_nonce`、`exam_attempts.client_nonce`、`op_queue`
- 断线续考与超时自动交卷：`getOrStartAttempt`、`sweepExpired`（每分钟扫描）
- 证书有效期与到期推送：`issueCertificate`、`/api/certificates/renew-scan`
- 成绩修改与补录审计：`audit()` 写入 `audit_logs`
