# 中药材 GAP 培训考核一体化 Web 平台

面向**中药材种植基地与饮片企业**，把「谁培训过、谁考过了、哪块地归谁管」三件事绑定在一起的全流程 Web 平台。
覆盖 **人员台账 → 工种标签 → 培训排课/签到 → 课件学习 → 考核组卷/答题/评阅 → 电子证书（有效期）→ 采收持证校验留痕 → 统计审计** 全闭环。

## 快速开始

```bash
npm install
npm start                 # 首次启动自动建表并写入演示数据
# 打开 http://localhost:3000
```

演示账号（密码均为 `123456`）：

| 账号 | 角色 | 数据范围 |
| --- | --- | --- |
| `qiye` | 企业质控 | 全量基地数据 |
| `admin` | 基地管理员 | 仅本基地，人员台账/排课/采收登记 |
| `tech` | 技术指导员 | 仅本基地，排课、代签、评阅、复核 |
| `farmer` | 药农（刘长贵） | 仅本人课程/考核/证书/通知 |

其他命令：`npm run seed`（重置演示数据）、`npm run reset-db`（删库）、`npm run test:api`（后端规则测试）、`npm run test:e2e`（浏览器端到端，需本机 Chrome/Chromium）。

## 技术栈

- 后端：Node.js + Express 5 + better-sqlite3（零外部服务，单文件 SQLite 落库）
- 前端：原生 ES Module 单页应用（无构建步骤），移动端适配手机答题/扫码
- 鉴权：登录 Token（内存会话），基于角色的访问控制 + 基地数据隔离
- 离线：localStorage 离线队列，弱网先存本地、联网后幂等补传去重

## 业务闭环与核心规则

**人员台账（基地管理员）**
- 姓名、身份证、所属合作社/地块、长期或季节性用工、联系方式
- CSV 批量导入（合作社按名称、地块按编号匹配）；身份证 或 姓名+手机号 命中即判定重复
- 重复人员自动合并：互补字段、迁移培训/签到/考核/证书/采收等关联记录，源档案标记失效
- 按工种挂技能标签（育苗/移栽/除草/施肥/植保打药/采收/初加工/仓储），每个标签绑定必需培训科目

**培训（技术指导员排课）**
- 时间、地点、地块、讲师、科目/定向工种、内容；按工种自动展开应到名单并推送通知
- 自动统计「应到/实到/缺课」，一键向缺课人员推送提醒
- 药农扫码报名、现场扫码签到；技术员可代签补录
- 签到幂等：同人同场次唯一约束 + `client_event_id` 防弱网重传；支持批量补传
- 药农可对讲师打分，汇总为讲师授课评分

**课程内容库**
- GAP 规范、农药安全间隔期、禁用农药清单、采收加工标准等文档/短视频
- 逐人记录观看时长与章节完成度；**未学完对应科目全部课件不能报考**
- 视频看满时长自动完成，文档显式标记完成；进度取最大值，重复上报不回退

**考核**
- 按药材品种、GAP 章节、难度（易/中/难按 50%/35%/余量分层）抽题
- 同一场次自动生成 **A/B 卷**（题目交替拆分）；可设开考时间、时长、及格线、补考次数
- 手机答题：每 15 秒+输入即自动暂存，断线刷新后恢复试卷、已答与剩余时间
- 超时由服务端**自动交卷**；交卷/答题均幂等 upsert，弱网重传安全
- 选择/判断/识图客观题自动判分；识图与简答题推技术员评阅，**两名评阅时自动取平均**
- 支持纸质卷成绩回录（直接出分、合格即发证）
- 药农可在线申诉，技术员复核可维持/驳回/调分，全程通知并写入审计日志

**电子培训合格证**
- 考核合格自动签发带编号电子证书（农药安全类科目有效期 24 个月，其余长期）
- 到期前 30 天扫描并自动推送复训提醒（同证书幂等不重复打扰）
- 支持扫码/链接验证真伪、打印导出、管理员撤销留痕

**采收登记（持证校验）**
- 录入地块与作业人员，逐人按其工种校验当期必需科目是否持有效证书
- 未持证给出红色警示，**必须逐人填写原因方可登记**，并通知基地管理员
- 校验结果、关联证书编号、原因全部随批次留痕，可一键导出 JSON 给下游客户/检查方调阅

**数据权限**
- 企业质控：全量基地；基地管理员/技术员：仅本基地；药农：仅本人数据

**统计分析**
- 按地块/合作社/科目维度的合格率
- 缺训名单（分场次）、每位药农年度学时（按实际签到时长）、讲师授课评分

**审计**
- 人员新建/修改/合并/导入、签到与代签补录、交卷与超时自动交卷、纸质录分、
  评阅/改分/双评、申诉复核、证书签发撤销、采收登记等全部写审计日志，可按对象/动作/人检索


## 关键接口（节选，均挂 `/api`）

- `POST /people/import`、`POST /people/merge`、`GET /people/duplicates/list`
- `POST /trainings/:id/signin`、`POST /trainings/signin-batch`、`POST /trainings/:id/remind-absent`
- `POST /courses/progress`（观看时长/章节完成）
- `POST /exams`（自动 A/B 组卷）、`POST /exams/:id/register|start|submit`、`POST /exams/answer`、`POST /exams/:id/paper-score`
- `POST /grading/answer/:id/grade`（双评取均）、`POST /grading/appeal/:id/review`
- `POST /certificates/sweep-expiry`、`GET /certificates/verify/:certNo`
- `POST /harvest/check-workers`、`POST /harvest/batches`、`GET /harvest/batches/:id`
- `GET /stats/pass-rate|missing-training|annual-hours|trainer-ratings`
